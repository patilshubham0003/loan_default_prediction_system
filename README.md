# Loan Default Prediction System

## Overview

The **Loan Default Prediction System** is a Machine Learning project that predicts whether a customer is likely to default on a loan or not.

The system uses customer and loan information such as income, credit score, loan amount, employment details, and other financial details to make the prediction.

## Objective

The main objectives of this project are:

* Predict loan default using Machine Learning.
* Analyze customer and loan-related information.
* Identify customers who may have a higher risk of loan default.
* Support data-driven loan decisions.
* Provide a simple and user-friendly application.

## Features Used

The system uses the following features:

* Age
* Income
* Loan Amount
* Credit Score
* Months Employed
* Number of Credit Lines
* Interest Rate
* Loan Term
* DTI Ratio
* Has Mortgage
* Has Dependents
* Has Co-signer
* Education
* Marital Status
* Employment Type
* Loan Purpose

## Machine Learning

The model is trained using historical loan data.

The target variable is:

* `1` = Loan Default
* `0` = No Loan Default

The project includes data preprocessing, feature transformation, model training, and model evaluation.

## Model Evaluation

The model is evaluated using:

* Accuracy
* Precision
* Recall
* Confusion Matrix

Recall is an important metric in this project because the system needs to identify customers who actually defaulted on their loans.
